Version 3.1.0 Nightly

A major stability-focused update with a redesigned Soduto Share extension, improved notifications, and numerous fixes.

✨ Highlights

  • Revamped Soduto Share extension with multi-device, multi-file, and text sharing
  • Entire unread conversation threads are now shown directly in notifications
  • More reliable notifications with better syncing, fewer duplicates, and improved icon handling
  • Large number of bug fixes and overall stability improvements

🌟 Enhancements

  • New SwiftUI-based Soduto Share interface with clear transfer states (transferring, success, fail)
  • Share multiple files, URLs, or text to multiple devices at once
  • Touch Bar shows device type icons with improved controls

🐛 Fixes

  • Correct device selection when sharing files
  • Improved Launch on Login reliability
  • More reliable notification icon handling and syncing
  • Various edge cases, crashes, and stability issues resolved

🔒 Security

  • Fixed a path traversal vulnerability that could allow a malicious device to write files outside the intended destination folder

⚙️ Under the hood

  • Modernized notification, logging, and connectivity systems
  • Internal cleanups and dependency maintenance
